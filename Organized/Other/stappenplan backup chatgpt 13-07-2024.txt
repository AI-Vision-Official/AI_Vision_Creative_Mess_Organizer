Ik had gekozen voor de mirror van de universiteit.
-Create een batch file op de volgende manier:
Kopieer de hele text tussen de lijntjes, exclusief de lijntjes. Pas 2 dingen aan, de input map en de output map

---------------------------------------

@echo off
setlocal enabledelayedexpansion

:: Stel het pad naar je basismap in
set BASE_DIR=C:\Users\RTX2060\Downloads\2024-07-12-conversations
:: Stel het pad naar je output map in
set OUTPUT_DIR=C:\Users\RTX2060\Downloads\2024-07-12-conversations\Output PDF

:: Zorg ervoor dat de output map bestaat
if not exist "%OUTPUT_DIR%" mkdir "%OUTPUT_DIR%"

:: Ga naar de basismap
cd /d %BASE_DIR%

:: Loop door alle submappen
for /r %%d in (.) do (
    pushd %%d
    :: Loop door alle Markdown-bestanden in de huidige submap
    for %%f in (*.md) do (
        echo Converting %%f to PDF...
        pandoc "%%f" -o "%OUTPUT_DIR%\%%~nf.pdf" --
    )
    popd
)

echo Conversie voltooid!
pause
